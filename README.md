# «Перекрёсток» — интерактивный редактор дорог

Сфокусированная версия генератора дорожной геометрии и инженерного оснащения, пока без печатных листов. Приложение предназначено для быстрого построения перекрёстков, полос движения, трамвайных путей, дорожной разметки, опор, камер и кабельных связей.

## Что работает

- Произвольные прямые и ломаные проезжие части. Дорога создаётся протягиванием мыши, узлы перетаскиваются; двойной щелчок добавляет точку изгиба.
- Выбранная ось подсвечивается и получает пикетаж. Каждый узел оси выбирается отдельно: доступны точные координаты, длины и углы соседних участков; Ctrl при перетаскивании сохраняет направление предыдущего участка, Shift — следующего.
- Контрольные поперечники добавляются непосредственно щелчком по оси. Для каждого поперечника независимо задаются наличие и ширина всех полос, а также плавный или линейный переход к следующей точке; асфальт, границы полос, трамвайные рельсы и продольная разметка перестраиваются как единая зависимая модель. Новую крайнюю полосу можно начать от выбранного поперечника с автоматическим отгоном.
- Автоматические зоны перекрёстков строго по границам проезжих частей, без выхода покрытия за край полос.
- Для Т-образного примыкания выбирается назначение: полноценный перекрёсток через всю дорогу (по умолчанию) или локальный съезд только до оси.
- В режиме «съезд · до оси» поверхность, полосы и разметка примыкающей дороги отсекаются одной геометрической полуплоскостью по оси основной дороги, поэтому косые и широкие ответвления не пролезают на встречную половину.
- На каждом подходе перекрёстка можно отдельно поставить светофоры слева, справа или с двух сторон, изменить их отступ от границы; символы автоматически следуют за углом дороги.
- Корпуса светофоров располагаются вдоль дороги, параллельно оси подхода; продольное положение регулируется отдельным ползунком.
- Инженерный слой содержит опоры ЛЭП, опоры освещения и консольные опоры. Опоры свободно перемещаются и поворачиваются, сохраняя все навесные элементы и кабельные связи.
- У консольной опоры отдельно настраиваются длина балки, начало рабочей зоны креплений и количество посадочных точек по сторонам А и Б. Точки каждой стороны независимо и равномерно перераспределяются по рабочей зоне при изменении их количества.
- На посадочные точки устанавливаются три условных обозначения по мотивам PDF-референсов: обзорная камера V, детектор фиксации S и радарный блок D. Камера жёстко привязана к выбранной точке и при перетаскивании перескакивает только между точками; свободного положения между креплениями нет.
- Камеры показаны как на монтажных схемах: крепление со стороны балки, вытянутый корпус, объектив или раструб на переднем торце. Подпись имени исходно продолжается вдоль направления объектива, автоматически разворачивается вместе с камерой и свободно переносится отдельной плашкой с линией-выноской.
- Внутри консольной опоры автоматически строятся отдельные UTP и КГтп к каждой камере: линии выходят из шкафа управления или узла «Феникс», расходятся по двум цветным магистралям вдоль балки и ответвляются к посадочным точкам. Кабели рисуются в верхнем инженерном слое со светлой подложкой и остаются видимыми поверх дороги, балки и оборудования. Автоподключение идемпотентно и создаёт только недостающие связи; отдельный кабель можно добавить вручную, переключить в ручной режим, разбить двойным щелчком и перетаскивать его точки изгиба.
- Подпись любой опоры вынесена в отдельную плашку с линией-выноской. Плашку можно свободно перетаскивать прямо на схеме либо задавать её смещение по X/Y в свойствах.
- К опорам прикрепляются условные обозначения из PDF-референсов: шкаф управления, точка питания, дополнительный электрощит, узел коммутации «Феникс» и микрокомпьютер обработки сигналов светофора.
- Между опорами прокладываются СИП, оптический кабель, UTP cat.5e и КГтп-ХЛ 2×2,5. Можно одним проходом выбрать цепочку из нескольких опор; каждый следующий щелчок создаёт очередной участок до нажатия «Завершить».
- Несколько кабелей между одной парой опор автоматически расходятся по параллельным невидимым направляющим. Автоматических названий и значений длины на самих линиях нет.
- Необязательная подпись добавляется вручную в свойствах кабеля. Её можно передвигать прямо на схеме, менять положение вдоль трассы, сторону и расстояние выноса; пустое поле полностью скрывает подпись.
- Вынос консольной опоры имеет широкую белую окантовку под тёмным штрихом и остаётся заметным поверх асфальта.
- Реальные дуги сопряжения внешней границы асфальта: для X-перекрёстка строятся четыре скруглённых угла, для Т-образного примыкания — два. Компактный единый радиус вычисляется автоматически как четверть ширины более узкой дороги и вручную не задаётся.
- Белая краевая разметка 1.2 проходит отдельной параллельной дугой внутри асфальтового покрытия. Прямые участки заканчиваются в точных касательных точках этой дуги, поэтому линия непрерывно уходит в скругление без разрывов.
- Внутренние области всех скруглений полностью заполняются асфальтом соединяемых дорог, включая косые и Т-образные примыкания. Обычные автомобильные полосы, центр узла и дуги используют единый цвет покрытия без заметных клиньев и стыков.
- Центральная зона перекрёстка и все дуги объединены в одну составную асфальтовую фигуру без отдельных обводок. Поэтому прямые дороги переходят в скругления без зазоров, ступенек и выступов. Серая окантовка полностью убрана.
- SVG-схема использует одинаковые параметры геометрии и сглаживания в Chromium-браузерах, включая Google Chrome и Яндекс Браузер.
- Скругление строится как цельная замкнутая асфальтовая фигура между двумя математически параллельными дугами и не зависит от особенностей сглаживания браузера.
- Названия улиц и их поля ввода убраны с рабочей области; дороги редактируются непосредственно через полосы, разметку и узлы.
- Кнопка «Начать заново» очищает дороги, перекрёстки и обозначения после подтверждения и открывает пустую рабочую область.
- Автоматические точки разделения у ответвления вычисляются как точные пересечения разметки с фактической границей узла. При перемещении или изменении угла дороги точки перестраиваются вместе с перекрёстком; они показаны небольшими оранжевыми ромбами и не дублируются ручными маркерами.
- Прямые и дуговые участки внешней границы асфальта и краевой разметки соединяются касательно с небольшим перекрытием, поэтому переход остаётся плавным при любом масштабе.
- Вспомогательная проектная граница строится поперёк каждого подхода через точки начала дуг, как на нормативной схеме границ перекрёстка.
- Каждый подход к узлу имеет собственное правило: приоритетное направление, «уступить» (1.13) или обязательная остановка. Стоп-линия 1.12 автоматически занимает только полосы, по которым транспорт въезжает на перекрёсток; на выездных полосах она не рисуется. Отступ от границы регулируется.
- У примыканий поверхность основной дороги перекрывает окончание присоединённой дороги: её полоса не продолжается диагональным клином внутри основной проезжей части.
- Для косых примыканий дуги вычисляются по фактическому углу между дорогами. Асфальт, краевая линия и точки остановки остаются состыкованными даже при больших отклонениях от прямого угла.
- Все ручные и автоматические точки разделения вынесены в самый верхний слой редактора и всегда остаются видимыми поверх дорог, перекрёстков, разметки и обозначений.
- Перекрёсток является функциональной точкой разделения дороги: продольная разметка заканчивается у границы узла, а участки до и после него выбираются и меняются независимо.
- В режиме «съезд · до оси» узел всегда обрезается именно осью основной дороги, в том числе у косых ответвлений. Осевая разметка не скрывается и динамически делится в двух точках на фактической границе примыкания.
- Ответвление от любой точки существующей дороги по умолчанию строится строго под 90° к её оси в обе возможные стороны. Во время построения показывается двусторонняя направляющая «А/Б»; сторону определяет положение указателя. `Alt` включает свободный угол, `Alt + Shift` фиксирует его с шагом 15°.
- Готовые заготовки: прямая улица, X- и T-образный перекрёсток, улица с трамвайными путями.
- Каждая полоса выбирается непосредственно на схеме и имеет собственные ширину, тип, направление и разрешённые манёвры.
- Все новые дороги, ответвления и шаблоны создаются для правостороннего движения: попутные полосы располагаются справа относительно направления построения оси, встречные — слева. Старые проекты с прежним зеркальным расположением автоматически исправляются при открытии.
- Стрелки направления не загромождают схему и появляются только на выбранной полосе; в экспортируемый SVG служебная подсказка не попадает.
- Автоматическая стоп-линия ограничивается внутренними краевыми линиями 1.2 и не выходит за пределы проезжей части.
- Автомобильные, трамвайные, маршрутные, велосипедные полосы и разделительные полосы.
- Добавление полос слева и справа от выбранной полосы.
- Остановка транспорта и пустой карман остаются локальными участками с двумя переходами. Расширение и сужение работают как крайняя полоса: расширение начинается в выбранной точке и продолжается до конца дороги, сужение идёт от начала дороги и исчезает в выбранной точке. Ширина полосы и длина единственного плавного перехода редактируются.
- Линия на общей границе участка с основной дорогой хранится как единый объект и меняется сразу по всей длине. Доступны отсутствие линии, 1.1, 1.5, 1.8 и 1.11; для расширения и сужения исходно используется обычная прерывистая 1.5 с теми же толщиной, штрихом и разрывом, что между стандартными полосами. В точке начала расширения или окончания сужения внутренняя и внешняя линии имеют общую вершину без зазора и наложения.
- Остановка транспорта автоматически получает жёлтую непрерывную зигзагообразную разметку 1.17.1 точно на оси существующей краевой линии: белая линия на длине остановки замещается, а зубцы направляются только внутрь кармана. Знак 5.16 ставится в начале посадочной площадки по направлению движения.
- Кликабельные линии между полосами и быстрый выбор 1.1, 1.2, 1.3, 1.5, 1.6, 1.7, 1.8 и 1.11 прямо на рисунке.
- Для комбинированной разметки 1.11 сторона сплошной линии переключается зеркально. Ориентация хранится отдельно у каждого участка между точками разделения и также доступна у единой линии примыкания дорожного кармана.
- Точки разделения разметки: одна линия делится на независимые участки, для каждого участка назначается собственный тип; соседние участки можно снова объединить.
- Наносимые обозначения: стоп-линия, «уступи дорогу», переход, остановка, стрелки 1.18, СТОП, маршрутный транспорт, велосипед и другие базовые обозначения.
- Сетка, снапы, панорамирование, масштабирование, undo/redo.
- Локальное автосохранение, перенос проекта через JSON и экспорт схемы в SVG.

Изображения намеренно условные и удобные для редактирования — это не копирование старых PDF. Номера и назначение разметки основаны на приложении 2 к ПДД РФ и действующем ГОСТ Р 51256-2018 с Изменением № 1. Итоговый проект организации дорожного движения должен проверяться профильным инженером.

## Запуск в Docker

```powershell
docker compose up --build
```

Открыть `http://localhost:3000`.

Остановка:

```powershell
docker compose down
```

## Локальная разработка

Требуется Node.js 22 или новее.

```powershell
npm install
npm run dev
```

## Управление

- `V` — выбор;
- `R` — новая дорога;
- `B` — ответвление от существующей дороги;
- `M` — поставить точку разделения на выбранной линии разметки;
- `H` — панорамирование;
- колесо мыши — масштаб;
- двойной щелчок по дороге — добавить узел изгиба;
- `Delete` — удалить выбранный элемент;
- `Ctrl+Z` / `Ctrl+Y` — отмена и повтор;
- `Esc` — выйти из текущего режима.

## Нормативная основа

- ПДД РФ, приложение 2 «Дорожная разметка и её характеристики» — постановление Правительства РФ № 1090.
- ГОСТ Р 51256-2018 «Технические средства организации дорожного движения. Разметка дорожная. Классификация. Технические требования», включая Изменение № 1.
